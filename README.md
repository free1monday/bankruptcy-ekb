# Первое банкротное бюро — сайт по банкротству физических лиц в Екатеринбурге

Статический лендинг на чистом HTML + CSS, без фреймворков. Светлый дизайн в тонах свободы: светло-коричневый, зелёный, облака, деревья. Деплой на Vercel через GitHub.

## Структура
- `index.html` — главная страница: банкротство физлиц, цифры, услуги, контакты
- `styles.css` — светлый дизайн: cream, зелень, облака, деревья
- `robots.txt` — разрешение индексации + ссылка на sitemap
- `sitemap.xml` — карта сайта для поисковиков
- `assets/mark.svg` — логотип (зелёные весы в ветви дерева)
