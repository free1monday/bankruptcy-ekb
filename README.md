# Помощь с банкротством физлиц — информационный сайт (Екатеринбург)

Статический лендинг на чистом HTML + CSS, без фреймворков. Светлый дизайн в тонах свободы: кремовый, зелёный, облака, деревья. Деплой на Vercel через GitHub.

## Концепция
Информационная площадка о помощи с банкротством физических лиц в Екатеринбурге. Не является рекламой конкретной фирмы. Упоминается партнёр — «Первое банкротное бюро» (руководитель — арбитражный управляющий Владимир Михайлович Шамои, БЦ Филитц, сайт pervoebankrotnoe.ru). Ссылка на партнёра размещена внизу (контакты и футер), не отвлекая от основного действия.

## Бизнес-модель
- Лиды приходят в Telegram `t.me/blast29` (менеджер проекта)
- Менеджер консультирует по банкротству физлиц и записывает на приём к партнёрскому арбитражному управляющему
- Договор заключается с партнёром, который получает вознаграждение как арбитражный управляющий

## Ссылки на сайте
- Telegram менеджера: `https://t.me/blast29`
- Основной сайт: `https://strange-cases.vercel.app`
- Сайт партнёра: `https://pervoebankrotnoe.ru/` (в контактах и футере, малый шрифт)

## Цифры (опыт партнёра)
- 2000+ успешных списаний долгов
- 500+ клиентов
- Скидки до 70% на процедуру банкротства

## Структура
- `index.html` — главная страница: о проекте, партнёры, как мы работаем, контакты
- `styles.css` — светлый дизайн: cream, зелень, облака, деревья
- `robots.txt` — разрешение индексации + ссылка на sitemap
- `sitemap.xml` — карта сайта для поисковиков
- `assets/mark.svg` — логотип (зелёные весы в ветви дерева)

## Деплой
Сайт привязан к Vercel, autodeploy через Git: `git push origin main` → автоматическая публикация на `https://bankruptcy-ekb.vercel.app`.
