# Помощь с банкротством физлиц — информационный сайт (Екатеринбург)

Статический лендинг на чистом HTML + CSS, без фреймворков. Светлый дизайн в тонах свободы: кремовый, зелёный, облака, деревья. Деплой на Vercel через GitHub.

## Концепция
Сайт не является рекламой конкретной фирмы. Он позиционируется как информационная площадка о помощи с банкротством физических лиц в Екатеринбурге, с упоминанием партнёра — «Первого банкротного бюро» (руководитель — арбитражный управляющий Владимир Михайлович Шамои, БЦ Филитц).

## Бизнес-модель
- Лиды приходят в Telegram `t.me/nettakihdel` (менеджер проекта)
- Менеджер консультирует по банкротству физлиц и записывает на приём к партнёрскому арбитражному управляющему
- Договор заключается с партнёром, который получает вознаграждение как арбитражный управляющий

## Структура
- `index.html` — главная страница: о проекте, партнёры, как мы работаем, контакты
- `styles.css` — светлый дизайн: cream, зелень, облака, деревья
- `robots.txt` — разрешение индексации + ссылка на sitemap
- `sitemap.xml` — карта сайта для поисковиков
- `assets/mark.svg` — логотип (зелёные весы в ветви дерева)
