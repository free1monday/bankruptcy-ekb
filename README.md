# Первое банкротное бюро — сайт по банкротству физических лиц в Екатеринбурге

Статический лендинг на чистом HTML + CSS, без фреймворков. Деплой на Vercel через GitHub.

## Структура
- `index.html` — главная страница: банкротство физлиц, цифры, услуги, контакты
- `styles.css` — чёрно-красный дизайн в стиле Stranger Things
- `robots.txt` — разрешение индексации + ссылка на sitemap
- `sitemap.xml` — карта сайта для поисковиков

## Бизнес-модель
- Сайт представляет «Первое банкротное бюро» (руководитель — арбитражный управляющий Владимир Михайлович Шамои, Екатеринбург, БЦ Филитц)
- Лиды приходят в Telegram `t.me/nettakihdel` (менеджер проекта)
- Менеджер ведёт клиента к Владимиру на консультацию, заключается договор, Владимир получает вознаграждение как арбитражный управляющий

## Цифры на сайте
- 2000+ успешных списаний долгов
- 500+ регулярных клиентов
- Скидки до 70% на процедуру банкротства
- Рассрочка

## Деплой
Сайт привязан к Vercel, autodeploy через Git: `git push origin main` → автоматический публикация на `https://bankruptcy-ekb.vercel.app`.
